📋 Hướng dẫn sử dụng

  1. Custom Chat: Đã hoạt động ngay! Mở website và tìm nút chat ở góc phải dưới 💬
  2. Tawk.to: Đăng ký tại tawk.to, lấy Property ID và Widget ID
  3. Facebook Messenger: Tạo Facebook Page, lấy Page ID và cấu hình plugin
  4. Zalo OA: Đăng ký tại oa.zalo.me, lấy OA ID
  5. Chi tiết: Xem file CHAT_QUICK_START.md để biết cách cấu hình

💡 Tip: Nên sử dụng 2-3 kênh chat để phục vụ khách hàng tốt nhất!
